"# inventory-audit-analyzer" 

"## Overview
Project goal is to simulate an inventory cycle count to identify discrepancies, measure accuracy of inventory and determine operational risks within the inventory.

"## Problem
Inventory team cannot rely on simply counting by hand and expect accurate results. They need a quick way to identify and fix count errors, correct shortages, and resolve discrepancies. This will come in handy for audits and budget corrections.

"## Tools
    Python
    SQl
    Excel/PowerBI
    Github

"## Planned Features
    Clean raw inventory data
    Calculate quantity variance
    Flag discrepancies
    Analyze storage/product accuracy
    Distinguish discrepancy urgency
    Build a dashboard for operational reports
