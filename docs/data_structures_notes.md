# Data Structures Reference

# Faster
O(1): Constant Time - Operation time never changes, depsite size. Example: Accessing a certain point within an array.
O(n): Linear Time - Operation grows with size
Example: Using a single loop to move through an array.
O(log n): Input gets larger by one each time data doubles
Example: Binary search in pre-sorted array.

# Slower
O(n^2): Quadratic Time - Exponatnial growth
Example: usualy in nested loops like bubble sort
O(n log n): Linearithmic Time - Combines linear and logarithmic
Example: Merge and Head sorts.
O(2^n): Exponential Time - Required time doubles very operation.
Example: Brute force guessing of passwords.
O(n!): Factorial Time - Operations become impossible very quikcly, only good for short imputs.
Exmamle: Permutating through every possble combonation in a set.
